# 农场卡牌：荒野远征

融合 QQ 农场经营 + 卡牌收集 + 搜打撤远征的 2D 网页游戏。

## 玩法

- **农场经营**：种植作物、育种温室、卡牌工坊、物资仓库
- **远征搜打撤**：进入荒野地图，打怪、开宝箱、占防御塔、完成任务后撤离
- **兽潮防守**：每波兽潮来袭时躲进已占领防御塔射程获得减伤
- **Boss 战**：任务完成后区域首领现身，四技能循环（地裂震荡 / 狂暴冲锋 / 召唤兽群 / 暗影弹幕），血量低于 50% 进入阶段二强化

## 技术栈

- 纯前端 Canvas2D + 原生 JavaScript，无框架依赖
- 逐像素渲染管线（地形烘焙、迷雾 CPU 缓冲、软件粒子）
- localStorage 存档

## 运行

直接用浏览器打开 `index.html` 即可，或起一个静态服务器：

```bash
npx serve .
```
