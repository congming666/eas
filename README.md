# 农庄牌：荒野远征 v1.5

## v1.5 家园补给与写实环境

- 新增 7 天循环每日奖励，连续签到可获得递增的金币、种子与少量材料。
- 新增开荒保障：金币低于 60 或种子耗尽时，每天可领取一次，将资源补至 120 金币与 3 种子。
- 每日奖励、连续天数与保障领取状态均写入本地存档，刷新页面不会重复领取。
- 家园背景加入自然天空、远山、草坡、田垄与木栅栏层次；远征地图改为更克制的自然色，并使用弯曲道路和不规则田块。

一款把永久农场经营、卡牌式技能配置与“搜索—战斗—撤离”结合起来的单人浏览器游戏原型。

## 开始游戏

直接双击 `index.html`，用 Chrome 或 Edge 打开即可游玩，不需要安装、登录或联网。

## 核心流程

1. 在家园农场播种并等待作物成熟。
2. 收获作物，获得金币、种子和材料。
3. 选择 T1–T4 远征地图并支付入场费。
4. 携带常驻技能和一次性消耗品进入地图。
5. 搜索宝箱、对抗怪物与 AI 掠夺者、占领防御塔。
6. 在 12 分钟内通过边缘撤离点或信号弹成功撤离。
7. 把金币、材料和新作物种子带回永久家园。

## v1.4 立体荒野与强化卡配置

- 远征地图加入树木、岩石、草垛、围栏、废墟与灾变晶体等伪 3D 障碍物，并带阴影、高光、侧面和实体碰撞。
- 怪物、宝箱、防御塔与掠夺者生成时会避开障碍物，减少重叠与穿模。
- 远征准备大厅新增强化卡携带区，可自由选择或卸下，最多携带 3 张。
- 携带的强化卡在本次远征中临时提高对应技能等级，不消耗卡牌；仍可在卡牌工坊永久使用。

## v1.3 农场与技能成长

- 新存档初始开放 8/36 块农田，之后依次消耗金币与材料扩建
- 作物可能出现干旱、虫害和杂草，格子直接显示状态图标
- 收获作物有概率掉落普通、稀有或传说强化卡
- 卡牌工坊可以永久提升四项基础技能，最高 8 级
- 技能升级会增强伤害、控制时间、位移或隐身，并降低能量与冷却成本
- 常驻技能和消耗品分栏显示，加入品质边框、环形 CD、释放及消散动画
- 加入三分钟撤离压力提示、低生命屏幕警告和信号弹暴露反馈

## 操作

- `WASD`：移动
- 鼠标左键：普通攻击或与宝箱、防御塔、撤离点交互
- 鼠标右键：拾取附近的地面战利品
- `Shift`：冲刺
- `1`–`4`：常驻技能
- `Q`：草药包扎包
- `R`：荆棘狂潮
- `E`：撤离信号弹
- `Esc`：暂停/继续
- 左下角音乐控件：开关背景音乐并调节音量

## v1.2 场景与交互升级

- 农场经营界面与远征准备界面完全分离
- 新增独立远征大厅，用于选地图、查看技能和配置消耗品
- 宝箱及敌人战利品会掉落到地面，需要靠近后右键拾取
- 加入荆棘、捕兽夹、毒孢子和落雷符文等环境陷阱
- 水域和泥地会影响移动速度
- T1–T4 拥有萤火、风沙、毒雾和异界雨等不同天气表现

## v1.1 视觉与音频升级

- 全新深色玻璃质感主菜单、农场面板和资源栏
- 技能卡显示伤害/控制值、能量消耗、冷却与消耗品价值
- 四级地图使用不同配色、地标和装饰物
- 随机生成道路、水域、耕地、树林、废墟与污染区域
- 加入无外部版权素材依赖的程序化背景音乐

## 存档

游戏会在浏览器本地自动保存：

- 金币、种子、材料
- 36 格永久农田与作物生长时间
- 已解锁作物和当前播种选择
- 地图选择和消耗品配置

清理该页面的浏览器本地数据会重置存档。
