# 农场卡牌：荒野远征

一款由个人独立设计和开发的浏览器端游戏，将农场经营、卡牌成长、沙盒战斗与限时撤离玩法结合在一起。

玩家在家园种植作物，获取金币、治疗道具、一次性技能卡和永久强化卡；整备武器与卡组后进入远征地图，探索物资、完成任务、占领防御塔、抵御兽潮、击败 Boss，并在倒计时结束前携带战利品撤离。

## 在线体验

- GitHub Pages：[开始游戏](https://congming666.github.io/eas/)
- 推荐使用最新版 Chrome 或 Edge。
- 首次加载需要下载游戏脚本和图像资源，请稍候片刻。

也可以下载仓库后直接使用浏览器打开 `index.html`。游戏不需要注册账号，进度保存在当前浏览器的 LocalStorage 中。

## 核心玩法

### 家园农场

- 小麦成熟后提供金币。
- 向日葵产出永久技能强化卡。
- 西瓜产出可在远征中使用的一次性技能卡。
- 卷心菜提供恢复类道具。
- 农田开局只解锁部分格子，其余地块需要消耗金币和材料扩建。
- 作物可能出现干旱、虫害和杂草等状态。
- 包含每日奖励、连续签到和资源不足时的低保机制。

### 卡牌与成长

- 强化卡分为普通、稀有、史诗和传说品质。
- 出发前最多选择 3 张强化卡。
- 强化卡可以临时提升本次远征能力，也可以在卡牌工坊中永久强化基础技能。
- 一次性卡牌在远征中消耗，并提供治疗、范围伤害或撤离能力。

### 荒野远征

- 四张难度递增的沙盒地图，具有独立配色、天气、陷阱和敌人配置。
- 摄像机跟随玩家移动，地图包含道路、水域、障碍物、宝箱、防御塔和撤离点。
- 战争迷雾会隐藏未探索区域中的怪物、物资和撤离点。
- 支持近战镰刃、豌豆连弩和藤芯法杖三种差异化武器。
- 四项主动技能包含范围攻击、藤蔓控制、位移突进和烟雾隐身。
- 地面物资需要靠近后使用鼠标右键拾取。
- 在限定时间内可以通过固定撤离点或信号弹撤离。

### 防御塔与兽潮

- 远征期间会周期性出现兽潮，并且波次强度逐渐提高。
- 玩家可以占领敌方防御塔，也可以修复损坏的防御塔。
- 已占领防御塔会自动攻击范围内的怪物。
- 兽潮期间防御塔获得额外射速和伤害。
- 玩家处于己方防御塔射程内会获得护盾减伤；离开保护范围则会承受更高的兽潮伤害。
- HUD 会显示下一波倒计时、剩余怪物数量和当前保护状态。

### Boss

- 完成远征任务后会召唤地图 Boss。
- T1 专属 Boss：苔岩裂颚兽，具有岩甲、巨口、背刺和长尾造型。
- T2 专属 Boss：幽潮骨翼龙，具有蓝黑鳞甲、双角、骨翼、卷尾和青蓝能量特效。
- Boss 使用斜俯视伪 3D 素材，并包含实体阴影、呼吸起伏、受击高亮和专属血条。

## 技术实现

- HTML5、CSS3、JavaScript
- Canvas 2D + PixiJS/WebGL
- LocalStorage 本地存档
- WebP 图像资源
- GitHub Pages 自动部署

项目按照职责拆分为：

```text
js/
├─ config.js         游戏配置、地图和数值
├─ save.js           本地存档与恢复
├─ ui.js             界面、提示与音频控制
├─ card.js           卡牌库存、品质和技能强化
├─ farm.js           农田、作物与收获系统
├─ expedition.js     地图、战斗、怪物、任务与撤离
├─ performance.js    空间哈希和地形区块缓存
├─ pixi-renderer.js  PixiJS WebGL 动态特效层
└─ game.js           场景切换和固定步长主循环
```

## 性能优化

- 游戏逻辑使用固定 60Hz 步长，画面绘制跟随显示器刷新率。
- 单帧限制最大逻辑补算次数，避免卡顿后出现怪物瞬移、伤害异常和冷却跳变。
- 使用空间哈希减少障碍物碰撞和防御塔索敌时的全量遍历。
- 静态地形按 512×512 区块缓存到离屏画布，摄像机只绘制当前可见区块。
- 战争迷雾以 120ms 间隔更新，减少重复遮罩计算。
- 普通粒子和烟雾由 PixiJS WebGL 层进行 GPU 加速绘制。
- PixiJS 无法初始化时保留 Canvas 回退路径。
- Boss 和地图资源使用 WebP 压缩，降低网络加载体积。

## 地图与战斗内容

- 差异化怪物行为：野猪冲锋、飞虫拉扯、狼群包抄。
- 精英怪、AI 掠夺者和地图分级 Boss。
- 随机任务：击杀、开启宝箱、占领防御塔。
- 地图事件：灵雨、血月、峡谷迷雾和晶石坠落。
- 环境陷阱：荆棘、捕兽夹、毒孢子和落雷符文。
- 2.5D 表现：近大远小、实体阴影、前后遮挡、冲刺残影、受击浮空和镜头震动。

## 存档内容

游戏会自动保存：

- 金币、种子和材料。
- 农田解锁状态、作物种类及成长时间。
- 卡牌库存、技能等级与出发配置。
- 每日奖励、连续签到和低保领取状态。
- 武器、地图和消耗品选择。

清理浏览器中该页面的站点数据会重置本地存档。

## 本地运行与验证

直接打开 `index.html` 即可游玩。若浏览器限制本地资源，也可以在项目目录启动任意静态文件服务器。

项目包含浏览器回归脚本，用于检查模块加载、武器切换、弹道、技能、任务和远征流程；JavaScript 文件也会进行语法检查。

## 当前边界

当前版本是可完整体验核心循环的单人浏览器游戏，暂未包含：

- 联机 PvP 或多人合作。
- 云存档和账号系统。
- 手柄及完整移动端触控适配。
- T3、T4 的定制高精度 Boss 素材。
