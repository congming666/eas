# 《农庄牌：荒野远征》游戏策划拆解分析

> 版本基准：**v5.4.0「荒野校准」**
> 文档性质：项目设计复盘 / 策划视角系统拆解 / 面试陈述底稿
> 数据来源：v5.4 千局平衡跑批（r4 权威全量级 + r5 定向验证）、30 档经济闭环模拟、`docs/game_data.json`
> 统计口径：bot 为确定性规则 AI，验证的是"配装可行性与数值断点"，**不代表真人分布与乐趣体验**

## 1. 项目概况

| 项 | 内容 |
|---|---|
| 游戏名 | 农庄牌：荒野远征（Farmbound Expedition） |
| 品类 | 搜打撤（Extraction）× 农场经营（Meta）× Roguelike |
| 平台 / 技术 | 网页游戏，纯 Canvas2D + 原生 JS，零构建，file:// 双击直开 |
| 单局时长 | 设计目标 3–5 分钟；bot 实测均值 131.9s |
| 核心参考 | 《逃离塔科夫》的装备风险机制 + 《星露谷物语》的农场积累 + 《Hades》的局内构筑与 Heat |
| 内容规模 | 4 Tier / 24 张子地图 / 12 Boss / 23 种怪物 / 23 种作物 / 5 把武器×10 级 / 16 技能×5 级 / 26 种消耗品 / 14 种具体资源 |
| 工程亮点 | 22 事件本地埋点、5 画像无头 bot（单轮 1088 局）、Wilson 置信区间、单杠杆 A/B、经济闭环模拟、nightly CI |

### 一句话定位

> **一个在末世荒野里种田屯资源、每次下场都赌命换装备的生存者。农场是可再生的后勤基地，远征是高风险的搜刮战斗——撤离成功滚雪球，死亡则装备全损。**

## 2. 核心幻想与设计支柱

### 2.1 核心幻想（Core Fantasy）

"安全感积累"与"赌命紧张"两种情绪的交替：农场让玩家慢慢变强、获得掌控感；远征用装备永久损失制造压力，逼玩家在贪婪与止损之间做决断。

### 2.2 设计支柱（一切系统取舍的裁决标准）

1. **农场必须不可替代**：武器材料只能种出来，修为只能升角色，两条成长线资源强制分离——杜绝"只打架不种地"或"只种地不下场"的单边玩法。
2. **撤离是玩家主动做出的、有代价的决策**，而不是打完 Boss 的自动结算。
3. **难度靠机制区分，不靠单一数值乘区**。
4. **所有数值结论必须可复算、可复测**：设目标曲线 → 跑批验证 → 找根因 → 改机制 → 复测，不靠手感拍板。
5. **单人项目的内容密度优先于系统数量**：新增系统必须能接入既有闭环，否则砍掉。

## 3. 核心循环拆解

### 3.1 三层循环

| 层级 | 时间尺度 | 循环内容 | 主导情绪 |
|---|---|---|---|
| 微观循环 | 秒级 | 移动 / 风筝 / 攻击 / 完美闪避 / 喝药 / 放置战场植物 | 操作反馈、读招博弈 |
| 局内循环 | 分钟级（均 132s） | 落地 → 搜刮打野 → 兽潮持续加压 → 岔路三选一 → Boss/宝箱 → **撤不撤** | 紧张 → 贪婪 → 决断 → 释放 |
| 局外循环 | 小时～天级 | 种地 → 材料 → 锻造/加工 → 配装 → 档案突破 → 挑战更高 Tier | 积累、掌控、长期目标 |

### 3.2 循环流向图

```
        ┌──────────────────── 农场（局外 Meta）────────────────────┐
        │  种地/温室 → 作物材料 → 锻造武器 · 加工消耗品 · 战场植物种子  │
        │     ↑                                      │              │
        │  稀有种子/异化样本/金币/档案图纸            ↓              │
        │     ↑                              配装、选图、选难度        │
        └─────┬──────────────────────────────┬───────────────────────┘
              │ 撤离成功带回                   │ 带入装备（死亡全损）
              │                               ↓
        ┌──────────────────── 远征（局内 Roguelike 搜打撤）──────────┐
        │  搜刮 → 打野/精英/Boss → 岔路选择 → 兽潮加压 → 撤离读条      │
        │  决策点：继续贪（更高收益） vs 立刻撤（保住已有）             │
        └───────────────────────────────────────────────────────────┘
```

### 3.3 关键裁决：双向资源流

- **农场 → 远征**：武器（作物材料锻造）、消耗品（工坊加工）、战场植物种子、角色等级（修为）。
- **远征 → 农场**：买不到的稀有种子、异化样本（种出专属消耗品）、金币、解锁建筑的档案图纸。
- **资源分离**：修为只进角色修行台；武器锻造/升级只吃作物材料。铁匠铺 UI 逐项标注"持有/需要 · 来源作物"，保证每种材料都有可种植的获取路径。

## 4. 局内设计：搜打撤为什么成立

### 4.1 品类成立的四个必要条件（自检表）

| 必要条件 | 游戏内对应机制 |
|---|---|
| ① 投入有代价 | 带入武器/消耗品死亡永久损失；入场费 |
| ② 收益不确定 | 掉落权重表、宝箱、精英/Boss、随机事件、岔路三选一 |
| ③ 撤离是主动且有压力的选择 | 固定撤离点读条、信号弹冒险撤离（刷怪围攻）、兽潮持续加压、撤离点 40px 清怪半径兜底 |
| ④ 损失可恢复、不会一次崩盘 | 农场材料可再生，构成与硬核搜打撤的差异化——受众更休闲、挫败可控 |

### 4.2 风险曲线（局内张力来源）

- **兽潮指数加压**：首波 20s；**每波刷出即开始下一波倒计时**（不等清场），间隔 `40×0.88^(n-1)`（下限 12s），数量 `(12+4×Tier)×1.34^(n-1)`，密度上限 `32+10×Tier`。时间越久，压力指数上升——直接给"贪"定价。
- **背包超重**：占用超过 12 格后移速衰减 `max(0.82, 1−0.045×(已用格−12))`，捡得越多跑得越慢。
- **金币占格**：每 100 金币占 1 格，不足 100 自动合并——连"捡钱"都进入格位取舍。
- **安全箱**：1–3 格死亡必保留，是"贪还是稳"的明确折中阀。

### 4.3 Boss 设计：软狂暴双向收束

- **问题原型**：复测发现 Boss TTK 中位仅 6.6s，但存在 68–265s 的长尾（低 DPS 配装打不死、高 Tier 兽潮围死撤离点导致超时）。
- **机制解法**（v5.4）：开战 50s 起每 22s 升一阶——
  - 进攻端：攻速/伤害阶梯上升、攻击间隔缩短，**封顶 4 阶**（防止一拳秒人，保住公平性）；
  - 防御端：Boss **受伤递增 +12%/阶，不封顶**（玩家长期打不死时，Boss 防御崩坏被收束）；
  - 召唤上限不放宽，避免数值雪崩。
- **HP 标定方法**：`HP = 准入等级配装 DPS × 目标 TTK`，逐只标定（3800–180000），不用"倍率拍脑袋"。
- **效果**：r5 定向 32 局 Boss 战 **0 超时**，最长战斗 167.8s（触发 6 阶后被收束）；中位战斗时长基本不变——只切掉异常尾部，不影响正常体验。

### 4.4 其他局内系统

- **战场植物**：辣椒火焰陷阱、向日葵视野灯、藤蔓减速、西瓜爆炸、稻草人嘲讽、月光菇治疗等，把农场"种"进战场，鼓励用地形和布置打架。
- **Roguelike 岔路**：定时三选一（宝箱/战斗/商店/篝火），每局路线不同。
- **精英词缀**：基础词缀（狂暴/迅捷/吸血/分裂）+ T3/T4 高层专属（护盾/反伤/召唤/免疫），噩梦难度精英必带 2 词缀。
- **操作深度**：连击、完美闪避（出手后 150ms 窗口，触发慢动作+必暴+怒气）、怒气超杀、处决（限定精英/Boss 残血，1.5s 内）。

## 5. 局外 Meta 设计

| 系统 | 作用 | 闭环位置 |
|---|---|---|
| 修行台（100 级） | 生命/攻击/防御/能量/回血成长；卡槽 Lv20/40/60/80 从 1 增至 5 | 消耗修为（90% 种地 + 10% 远征）；突破等级卡档案任务 |

| 图鉴（6 分页） | 作物/怪物/Boss/武器/道具/资源，标注作用与来源，未发现显剪影 | 收集驱动 |
| 成就殿堂 | 远征/农场/收藏三类成就 | 长线目标 |
| 难度 + Heat | 休闲/普通/困难/噩梦 + 通关后自选负面修改器换奖励倍率 | 终局自虐挑战 |

### 阵亡惩罚

远征死亡 50% 概率降 1 级（扣除本级修为，最低 Lv1）；消耗"免死令"可免除（档案奖励/稀有掉落）。风险与保护道具并存。

## 6. 数值体系

### 6.1 核心公式

- **最终伤害**：`[武器ATK × (1 + 基础ATK/50) + 基础ATK×0.2] × 技能系数 × 暴击 × 难度系数 × (1 − 减伤率)`
- **减伤率**：`防御 / (防御 + 150)`
- **升级修为需求**：`60 × Lv^1.4`（另加金币与泥土/清水/堆肥）
- **100 级属性区间**：生命 100→900、基础攻击 12→92、防御 0→60、能量上限 100→200、能量回复 15→21/s、脱战回血 0→4/s

### 6.2 两维难度结构（v5.4 重做）

- **Tier = 单调硬曲线**（基础强度）：怪物 HP `[1.15, 1.5, 2.4, 3.8, 5.6]`、伤害 `[1.1, 1.25, 1.95, 2.9, 4.0]`。
- **难度 = 平移 + 机制**：

| 难度 | 怪HP | 怪伤害 | 补给 | 视野 | 机制差异 |
|---|---|---|---|---|---|
| 休闲 | ×0.7 | ×0.7 | ×1.3 | ×1.05 | — |
| 普通 | ×1.0 | ×1.0 | ×1.0 | ×1.0 | 基准 |
| 困难 | ×1.55 | ×1.45 | ×0.7 | ×0.92 | 精英至少 1 词缀 |
| 噩梦 | ×2.3 | ×2.1 | ×0.35 | ×0.82 | 精英必带 2 词缀、火把消耗 ×2 |

> 设计要点：高难度的差异补在**机制**（补给稀缺、信息受限、词缀密度）上，而不是把一个乘区调到劝退。

### 6.3 目标曲线带（验收口径）

| 画像/维度 | 目标撤离率 | r4 实测 |
|---|---|---|
| 满级配装 T1→T4 | 90% → 60–65% | 88/94/92/80%（T4 偏高，见问题诊断） |
| 新手 休闲→噩梦 | 90 / 75 / 55–60 / 45–55% | 74 / 65 / 41 / 20%（整体偏硬） |
| 新手 T1→T4 | 70% → 25–30% | 79 / 70 / 33 / 18%（基本落带） |
| 有限补给（frugal） | 30–40% | 普通 33.3% 命中；全画像 20.8% |
| 贪财（greedy） | 75–85% | 80.2% [71%, 87%] ✅ |
| 武器 +10 所需成功撤离 | 5–8 局 | 双线第 7 次成功撤离满级 ✅ |
| 全量超时率 | ≤2% | r4 实测 2.64%；r5 后投影 1.8–2.0%（待 nightly 确认） |

### 6.4 经济闭环

- **一把武器满级总消耗**：19150 金 + 铁 193 / 晶 62 / 精铁 11 / 魂烬 15 / 獠牙 7 / 纤维 4 / 木 6 / 石 6 / 毒腺 6 / 甲壳 4。
- **30 档局间继承模拟**：
  - 账号 A（纯远征、零农场）：30 档仅撤离 8 次、重铸 22 次、武器始终 Lv0、余 2199 金——**反证"不种地无法成长"**；
  - 账号 B（农场+远征双线）：13 个农场周期、4 次死亡重置，**第 7 次成功撤离武器 +10**，晚期瓶颈在獠牙/精铁与金币之间**交替出现**（避免金币独卡）。

## 7. 数据驱动平衡方法论（项目最大差异化亮点）

### 7.1 工具链

1. **埋点**（`js/telemetry.js`）：22 个对局/经营事件，本地 localStorage 采集 + 游戏内暗色数据看板。
2. **无头 bot**（`tools/balance-bot.js`）：Playwright 加载**真实游戏页面**，切断渲染、固定 1/60s 步长 + 虚拟时钟快进，驱动真实 `Expedition.update`；bot 会风筝、轮换技能、喝药、闪避、开箱、种植物、用信号弹、占塔、按时/残血/背包满撤离。
3. **5 类玩家画像**：

| 画像 | 模拟的玩家 | 验证目标 |
|---|---|---|
| oncurve 满级配装 | 随 Tier 准入成长的玩家 | 成长曲线是否跟得上内容 |
| baseline 新手 | 固定弱配装 | 纯内容难度、新手悬崖 |
| bosshunter 寻 Boss | 成就型、强杀 Boss | Boss TTK / 击杀率 |
| frugal 有限补给 | 只带 3 个草药包 | 消耗品经济与缺口 |
| greedy 贪财 | 背包满/残血才撤 | 贪婪曲线与最优撤离时长 |

4. **统计口径**：每格 n≥25；撤离率带 **Wilson 95% 置信区间**；相邻难度差异用**两比例 z 检验**，p≥0.05 一律标"噪声"，禁止用小样本下结论。
5. **实验方法**：单杠杆注入式 A/B（只改一个变量复跑）、经济双情景模拟、跑批按版本归档对比、GitHub Actions nightly 504 局。

### 7.2 r4 权威结果（1088 局 / 1060 有效 / 超时 2.64% / pageErrors=0）

- 整体撤离率 **69.8% [67.0%, 72.5%]**，均时长 131.9s，均击杀 215，均金 647。
- 新手配装随难度 74/65/41/20%、随 Tier 79/70/33/18% 单调——v5.3 的"难度非单调、全是噪声"问题已解决。
- 系统使用率：信号弹 30.8%、大招 5.0 次/局、处决 0.34 次/局、岔路 0.49 次/局（低使用率系统见问题诊断）。
- Boss TTK 中位：野猪王 20.5s、采石巨魔 13.2s、枯木精 11.2s、石像鬼 13s、魔像 17.5s、沼泽巫妪 9.4s、虫母 8.4s、炎魔 20.9s、深渊领主 8.7s、时空守望 8.5s、月之祭司 18s、竞技场冠军 6.3s。

### 7.3 一个完整的"数据→根因→机制→复测"案例（面试主讲）

- **现象**：v5.3 噩梦与普通难度通关率无显著差异；Boss TTK 有超长尾部。
- **根因**（不是靠猜）：① 构造函数 balance 快照在 `applyDifficulty` 之前结算；② 12 Boss 调用了不存在的 `getMultipliers`，异常被 try/catch 吞掉——**Boss 从未吃到难度系数**。
- **机制解**：修复乘区链路 + 软狂暴双向收束（进攻封顶、受伤递增不封顶）+ 兽潮密度上限 + 撤离点清怪。
- **复测**：r4 难度梯度恢复单调；r5 热点格超时率 11%→2.1%、Boss 队列 0 超时，且中位体验不变。

> 方法论自觉：**bot 证明"配装可行性"，不能证明"乐趣"**；长尾修复的全量投影（1.8–2.0%）未经全量级复测，已在报表中诚实标注，等 nightly 确认。

## 8. 问题诊断（按影响分级，附证据）

### P0｜成立性风险

1. **乐趣与情绪曲线从未被真人验证。** 现有结论全部来自规则 bot，无法回答"真人会不会紧张、想不想再来一把"。真人首局流失点、真实撤离时长分布、损失后的弃游率均是空白。
2. **新手前 5 分钟信息过载。** 23 作物 / 16 技能 / 26 消耗品 / 24 地图 / 14 资源过早全部露出；"种地→收获→首次 T1 撤离"的三步强制引导尚未实现。
3. **风险感两头不讨好。** 硬核玩家可能因农场材料可再生而觉得死亡不够痛；frugal 画像全难度撤离率仅 20.8%、51% 在草药耗尽后死亡，新手可能觉得太痛。痛感区间未对真人标定。

### P1｜深度与存在感问题

4. **24 张图目前主要是"数值/配色/词条差异"，空间玩法差异不足。** 移动与交互语法全图一致，地标叙事、可破坏物、巡逻队、高地洼地虽已部分落地但深度浅，玩家难以记住"我在哪张图打过"。
5. **"做了但没存在感"的系统。** 处决 0.34 次/局、岔路 0.49 次/局、信号弹 30.8%——要么触发条件苛刻、要么收益不可读，需要逐个做"简化、合并或删除"审查，而不是继续堆新系统。
6. **满级配装 T4 仍有 80% 撤离率**，终局压迫感不足；oncurve 是"Tier 准入配装"画像，"满级装备打全部 Tier"的严格曲线尚未设队列验证。
7. **表现层残留**：HUD/卡片仍有 emoji 兜底，铁匠铺材料来源文字在窄屏被裁切，美术语言未 100% 统一。

### P2｜长线与工程问题

8. **终局目标单薄**：100 级 + 12 Boss + 图鉴完成后缺少回流钩子（每日种子、赛季、结算分享）。
9. **已知技术债**：Excel"战场植物"sheet 导出不全、renderCastShadow 偶发 NaN（bot 禁渲染规避）、deathReason 分类退化、bot 交战半径与游戏统计口径不一致、economy bot 不模拟工坊精炼。

## 9. 优化建议与路线图

### P0（先验证，不扩系统）

1. **补真人验证闭环**：埋点已具备，组织 5–10 名真人测试，重点采集首局流失点、撤离时长分布、死亡到下一局的间隔（弃游信号）；用真人数据校准 bot 参数。
2. **三步新手引导**：种第一块地 → 第一次收获 → 带初始武器完成一次 T1 撤离；其余系统（工坊/温室/档案/Heat）锁定在该流程之后逐步解锁。
3. **痛感标定实验**：用 bot + 真人对照"死亡损失幅度"（仅掉消耗品 / 掉武器 / 掉等级）三档，找到"紧张但不弃游"的区间。

### P1（提深度、做减法）

4. **地图差异化从数值转向空间语法**：每张图固定 1–2 个导航地标 + 1 个独占交互（如 T2 枯井可埋伏、T4 竞技场无掩体纯战斗），让玩家能用地标复述战局。
5. **低使用率系统审查**：处决改为"Boss 专属终结窗口"强化存在感或删除；岔路提高出现频率并让收益差异可读；信号弹增加明确的高价值使用场景。
6. **终局压力**：新增"满级装备"画像队列验证 T4；Heat 与 Tier 组合扩展，给硬核玩家可追求的低胜率目标。

### P2（长线与打磨）

7. **回流钩子（低成本）**：每日随机种子 + 结算 MVP 卡片（最高连击/最低血量反杀/最值钱战利品）引导截图分享。
8. **表现统一**：清掉剩余 emoji 图标、修复 UI 裁切、补齐 Excel 战场植物表。
9. **工具化**：数值表从静态 Excel 走向配置热加载，降低调参成本（个人项目可延后）。

## 10. 面试陈述底稿（一页纸）

### 10.1 90 秒陈述结构

1. **定位（10s）**："独立设计开发的网页 Roguelike 搜打撤，农场经营做局外养成、搜打撤做局内高风险决策。"
2. **核心循环（20s）**：种地产材料 → 锻造配装 → 进场搜刮 → 在兽潮压力下决定贪还是撤 → 撤离物回农场滚雪球；死亡装备全损。
3. **设计裁决（20s）**：修为只升角色、武器材料只能种出来，强制两条线互相依赖；难度用机制区分而非堆数值。
4. **数据驱动（30s，重点）**：自研无头 bot 模拟 5 类玩家、单轮 1088 局、Wilson 置信区间、z 检验标噪声、单杠杆 A/B、30 档经济模拟。
5. **完整案例（10s）**："发现噩梦不难→查出 Boss 从没吃到难度系数→设计软狂暴双向收束→复测长尾 11%→2%，中位体验不变。"

### 10.2 可能的追问与应答要点

| 追问 | 应答要点 |
|---|---|
| 为什么种田 + 搜打撤？ | 情绪互补：积累的安全感 vs 下场的紧张；资源闭环让农场产出有出口、远征消耗有来源 |
| 难度怎么设计？ | 两维：Tier 单调硬曲线，难度平移；噩梦靠补给/词缀/视野等机制差异 |
| Boss 怎么平衡？ | HP 按 DPS×目标 TTK 逐只标定；软狂暴双向收束消灭长尾，进攻增益封顶保公平 |
| 数据和手感冲突怎么办？ | 数据负责发现问题和验证结果，机制解法靠设计推理；bot 不验证乐趣，乐趣要真人测试 |
| 项目最大不足？ | 只有 bot 数据没有真人数据；地图空间差异浅；部分系统使用率低——下一步是真人验证和做减法 |
| 你在项目里的角色？ | 独立完成设计、程序、数值、埋点、自动化测试与版本发布，用工程化方法支撑设计决策 |

### 10.3 三条可复用的设计洞察

1. **难度是机制，不是乘区。**
2. **长尾问题用双向收束机制解决，而不是无脑堆血或削伤害。**
3. **把平衡从手感玄学变成可复现实验，同时清醒知道实验的边界在哪里。**
